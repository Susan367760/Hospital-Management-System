# Hospital Management System

A web-based Hospital Management System built with **Python and Django** to simplify basic patient record management. The application provides a centralized interface for registering patients, viewing patient information, updating records, and managing patient data.

## Project Overview

The Hospital Management System is a Django-based web application designed to demonstrate how technology can support administrative operations in a healthcare environment.

It provides a simple dashboard and patient management functionality, with authentication to restrict access to authorized users.

## Features

- **Dashboard:** View an overview of patient records.
- **Patient Registration:** Add new patients and capture their details.
- **Patient Management:** View, update, and delete patient records.
- **Patient Search:** Search for patients using available information.
- **Patient Identification:** Automatically generate unique patient numbers.
- **User Authentication:** Register, log in, and log out.
- **Admin Panel:** Manage application data through Django's administration interface.
- **Responsive Interface:** Bootstrap-based design for different screen sizes.

## Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Navigate into the project directory

```bash
cd hospital_management_system
```

If your project contains a nested `hospital_management_system` folder, navigate into the inner folder containing `manage.py`.

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Create database migrations

```bash
python manage.py makemigrations patient
```

### 7. Apply database migrations

```bash
python manage.py migrate
```

### 8. Create an administrator account

```bash
python manage.py createsuperuser
```

Follow the prompts to create your administrator username and password.

### 9. Start the development server

```bash
python manage.py runserver
```

### 10. Access the application

Open your browser and visit:

- **Application:** http://127.0.0.1:8000/
- **Django Admin:** http://127.0.0.1:8000/admin/

## Database

The project uses SQLite as its default database.

The Patient model includes fields for:

- Patient number
- First name
- Last name
- Date of birth
- Gender
- Phone number
- Email address
- Residential address
- Emergency contact name
- Emergency contact phone number
- Date created and last updated

Patient numbers are automatically generated by the application.

## Security Considerations

This project is an educational and portfolio demonstration.

It is not intended for storing real patient or medical records. A production healthcare application would require additional security controls, including:

- Strong authentication and authorization.
- Role-based access control.
- Encryption of sensitive information.
- Secure file storage.
- Audit logging and activity monitoring.
- Data backup and recovery.
- Privacy and healthcare regulatory compliance.

Use fictional patient information when testing this application.
